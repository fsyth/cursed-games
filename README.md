# Cursed Games

#### Terminal games made using the Python Curses library

Python ships with Curses by default on Unix and it's pretty neat.

This repo just contains simple games that you can play in your terminal.

### Installation

```bash
python -m venv .venv
.venv/Scripts/activate
pip install -r requirements.txt
```

### Playing

Launch a game by running one of the python scripts in the repo root.

```bash
python chess_multiplayer.py
```

Games are controlled with **arrow keys** to move the cursor, **space/enter** for selection, and **q** to quit.

Note that some characters or formatting may display differently depending on your terminal and operating system.
